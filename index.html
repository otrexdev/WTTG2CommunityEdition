Welcome to the Game 2: Community Edition

Community made set of bug fixes and quality of life changes

What is this?

Welcome to the Game 2: Community Edition is as the name suggest, a community modification to fix some issues that the base game has. This includes instakill patches, softlock fixes and quality of life changes that don't impact the main gameplay.

The Bug Fixes

We fixed many game breaking bugs, while leaving in the speedrun tricks. Below are some examples of stuff we fixed:

  • Noir Instakill
  • Infiltrator Achievement not working
  • Random Elevator Softlocks
  • Power Outage Softlocks
  • and many more...

The Quality of Life

We also implemented a bunch of new quality of life features that aim to help beginners, such as:

  • New Tutorial Documents
  • Game Over Tips
  • Menu Tooltips

How To Install

  1. Download the zip file listed above
  2. Extract the WTTG2_Data folder into the game's installation directory, overwriting any existing files if prompted. WARNING: Do not delete the folder from your game installation.
